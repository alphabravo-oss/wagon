# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately via GitHub Security Advisories: select "Report a vulnerability" on the [Security tab for alphabravo-oss/wagon](https://github.com/alphabravo-oss/wagon/security). Do not report vulnerabilities in public issues.

## Supported Versions

The latest release and `main` are supported for security fixes.

## Configuration

See the [README configuration table](README.md#server--auth) for authentication settings. Set `HAULER_UI_PASSWORD`; `HAULER_UI_INSECURE_NO_AUTH` must not be used in production.
